# SWYNEX Task 2 — Exploratory Data Analysis

## Business Objective

The objective of this project is to perform Exploratory Data Analysis (EDA) on a cleaned passenger dataset and uncover meaningful patterns that influence survival outcomes. Rather than producing descriptive charts alone, this analysis focuses on generating actionable, data-driven insights similar to those expected from a junior Data Analyst in a corporate environment.

## Tools Used

* Python (Pandas, NumPy)
* Matplotlib
* Excel
* Jupyter Notebook

## Key Outcomes

* Cleaned and validated 891 passenger records
* Generated 5 analytical visualizations
* Identified demographic and socio-economic survival trends
* Documented statistical findings with business interpretation
